# Carrier loss-run email map

Maps a canonical carrier group to the mailbox that services loss-run
requests. `engine/loss_run.py` parses any line of the form
`- <Carrier Group>: <email>`.

These are published carrier service mailboxes. Entries that named an
individual rather than a team have been removed; those carriers simply fall
through to no contact, which the skill handles.

Copy to `emailmap.md` in this directory to extend it locally - that filename
is gitignored.
