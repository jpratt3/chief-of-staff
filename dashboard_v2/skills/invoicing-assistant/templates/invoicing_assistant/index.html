How this works
Each binder is scanned for its billing block — the page carrying premium, commission and charges — and read with layout preserved, so a label keeps the number printed beside it even inside a column table.

Every figure is checked against the total the binder itself prints. A row that reconciles is marked green; one that does not says by how much it is out, rather than quietly balancing.

Commission is taken as printed. Where only a rate is given, it is applied to the premium and marked computed. Every cell is editable before you export.

CN and billing ID come from config/clients.json; a blank one is flagged amber so it is fixed in config rather than typed into an invoice request.
