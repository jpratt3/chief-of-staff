How this works
Each binder is scanned for its declarations page, then read with layout preserved so labelled fields, column tables and cover letters all resolve. Carriers are matched against companymap.md and insureds against clients.json.

Extracted cells arrive blue; anything blank is flagged amber for you to fill in. Rows the engine is unsure about get a Rescan button that re-reads the whole document instead of just the top pages.

Drafts are grouped by carrier contact, so five binders with the same carrier produce one email listing all five policies.
